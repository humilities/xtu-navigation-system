## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1 引言</font>
### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1.1 编写目的</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">本测试计划用于规范湘潭大学导航系统整体测试工作，明确测试范围、测试环境、测试内容、测试进度、资源安排及风险管控，指导后续测试用例设计、测试执行、缺陷管理与测试总结，保证系统功能、性能、兼容性、稳定性达到上线交付标准。</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1.2 项目背景</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">湘潭大学导航系统基于 HTML+CSS+JavaScript + Node.js 开发，集成 Dijkstra 最短路径算法、校园地图展示、3D 导航页面、后端数据服务、校园点位数据管理等功能，面向校内师生实现校园景点路径规划与地图导航服务。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">2 测试目标</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">验证系统前端页面、地图展示、3D 页面、路径规划算法功能正确性；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">验证后端服务启动、依赖安装、数据库初始化、接口调用</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">可用性</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">验证系统在主流浏览器下的</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">兼容性</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">；</font>
4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">验证前后端联调全业务流程</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">稳定性</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">；</font>
5. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">发现系统潜在缺陷、界面问题、逻辑漏洞，推动修复闭环，保障项目可正常交付。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3 测试范围</font>
### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3.1 功能测试范围</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">前端模块：首页加载、校园地图渲染、地图缩放拖拽、点位选择、路径规划、3D 导航页面；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">算法模块：Dijkstra 最短路径计算逻辑正确性；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">后端模块：Node 服务启动、依赖安装、环境配置、数据迁移、数据库导入、API 接口请求；</font>
4. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">异常场景：起点终点相同、无可达路径、后端服务断开、网络异常。</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">3.2 非功能测试范围</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">浏览器兼容性：Chrome、Edge桌面端；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">页面性能：首屏加载速度、静态资源加载完整性；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">系统稳定性：连续操作无崩溃、无控制台报错。</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">服务器运维部署、域名配置；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">第三方浏览器小众版本、老旧 IE 浏览器适配；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">高并发压力测试。</font>
